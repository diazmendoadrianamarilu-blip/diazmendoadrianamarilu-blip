## 🇬🇧 English

### About me
I'm a software and data engineer who turns messy legacy data into reliable, production-ready systems.

- 🎓 **Academic ERP migration:** I designed and ran the migration of academic data (students, graduates, faculty and institutional catalogs) from a legacy database into **Ellucian Banner**. I wrote the SQL transformation layer, built the load templates and validated them with the technical team.
- 🔐 **Banner security & platform admin:** I restructured the Banner security role matrix and administered the Ellucian Ethos and Insights (WebFOCUS) consoles.
- 🔌 **APIs & integrations:** I build REST APIs with **Node.js** and **.NET** and integrate with Ellucian Ethos and Experience.
- 🤖 **Computer vision:** I built a desktop app that detects damage in heritage stone buildings with machine learning.
- 👩‍🏫 **Teaching:** I teach *Excel Intermediate + AI* at BIT EDU.
